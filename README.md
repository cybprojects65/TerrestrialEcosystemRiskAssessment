# Ecosystem Risk Assessment – Massaciuccoli Lake Basin wetland

This archive contains the complete workflow for assessing ecosystem risks in wetlands, using the case study of the Lake Massaciuccoli basin (Tuscany, Italy), with particular attention to the degradation of forest and grassland habitats and the resulting loss of biodiversity. It includes R scripts, input data and outputs from multiple spatial analysis methodologies.

The approach integrates:
- Cumulative analysis: overlap-based risk assessment,
- Structural analysis: unsupervised clustering (Multi K-means),
- Predictive analysis: dimensionality reduction and anomaly detection using a Variational Autoencoder (VAE) combined with Multi K-means.

A Qgis project, supporting the cartographic visualisation of data, is available on the Zenodo repository at the following link: https://doi.org/10.5281/zenodo.17160216

## Input data

### `input/`
- **`source_data_values.csv`**  
  Harmonized and standardized geospatial variables used as input for all analyses.  
  Each row represents a spatial unit (grid cell of approximately 50 m), while columns correspond to environmental, socio-economic, and ecosystem-related variables.

---

## Analysis scripts

- **`01_Overlap_and_standardization_Massaciuccoli.R`**  
  Computes the overlap-based ecosystem risk index after variable standardization.

- **`02_MultiKmeans_Massaciuccoli_with_sd.R`**  
  Performs Multi K-means clustering on standardised variables, testing multiple numbers of clusters (k = 5–30). Identifies the optimal number of clusters (K=*) and annotates the centroids into three levels of attention (closer, medium, low) for refinement analysis. 
  
- **`03_VAE_Massaciuccoli.R`**  
  Runs a Variational Autoencoder (implemented via an external Java model) for dimensionality reduction and anomaly detection (hidden node = 6-12). Downloadable from:
https://data.d4science.org/shub/E_RmlXSjJSbFVhZmVyT25YTFJJYlY1a3BJRWc0T0xueUVIOWNXamR3dStNV3RMZDl2WThJRE5rckY0b1cwWVU1Kw

- **`04_MultiKmeans_on_VAE_Massaciuccoli_with_sd.R`**  
  Applies Multi K-means clustering (k = 5–30) on latent representations generated by the VAE.

## Output data

### `output/Overlap/`
- **`risk1_overlap_standardized_no_na.csv`**  
  Final overlap-based ecosystem risk index, excluding missing values (NA).

---

### `output/MultiKmeans/`
Contains results of Multi K-means clustering on original standardized variables.

- **`seq_from05_to30_by1_n1000_sd/`**
  - `centroidi_annotated_*.csv`: annotated cluster centroids for each k.
  - `centroid_classification_assignment_*.csv`: spatial assignment of each observation to a cluster.

---

### `output/MultiKmeans_on_VAE/`
Contains clustering results based on VAE latent space.

- **`seq_from05_to30_by1_n1000_sd_1&2_quartile/`**
  - `centroidi_annotated_*_on_VAE_*.csv`: annotated centroids in latent space.
  - `centroid_classification_assignment_*_on_VAE_*.csv`: cluster membership for each spatial unit.

---

### `output/VAE_varational_auto_encoder/`
Outputs generated by the Variational Autoencoder.

- **`hidden_node_mean.xlsx`**  
  Mean values of latent variables.

- **`out_2024_pr_n*/`**  
  Model runs with different numbers of hidden nodes:
  - trained model files (`.bin`, `.mat`, `.net`)
  - training and testing logs
  - classification outputs
  - selection of high-risk anomalies based on latent representations

---

### `output/interpretation_high_attention_cluster_MKM_MKMonVAE/`
Excel sheet for refinement analysis and classification of high- and medium-risk clusters, interpreting the centroids derived from both Multi K-means and Multi K-means on VAE and annotated as “closer attention”.
